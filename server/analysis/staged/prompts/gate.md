# 다르게 쓴 말 거르기

같은 일을 전하는 두 문장 L(원문 기사)과 R(다른 언론사)을 어절마다 번호를 붙여 보여 준다(L3, R7처럼). 프로그램이 상대 문장에 없는 어절을 후보로 골라 두었다(`후보`). 후보마다 세 칸을 보기에서 고른다. 오래 생각하지 말고 문장에 드러난 대로 답한다. 이유는 쓰지 않는다.

짝 머리에 `(이름만)`이 붙은 짝은 두 문장이 서로 다른 일을 전한다. 그런 짝에서는 같은 대상을 부르는 이름끼리만 비교한다. 이름이 아닌 후보는 `kind` = `other`다.

- `cp`: 상대 문장에서 이 후보와 같은 자리에 있는 어절 번호들(붙어 있는 어절 1~3개). 같은 대상을 부르는 말, 같은 행위를 서술하는 말, 또는 이 후보가 꾸미는 말이 상대 문장에서 놓인 부분이다. 없으면 빈 목록이다.
- `who`: 이 후보는 누구의 말인가
  - `rep`: 기자가 쓴 말
  - `quote`: 따옴표 안의 말, 또는 '-다고/-라고/-라며/-다는'으로 옮긴 발언 내용
  - `unclear`: 알 수 없음
- `kind`: 후보와 `cp`는 어떤 관계인가
  - `other`: 같은 사실의 같은 부분이 아니다(다른 행위, 다른 대상, 다른 발언, 출처 표시와 내용). `cp`가 없을 때는, 후보가 꾸미거나 평가하는 대상이 상대 문장에 없으면 `other`다.
  - `fact`: 한쪽에만 있는 사실 정보다(숫자, 이름, 날짜, 배경, 추가된 일).
  - `syn`: 같은 뜻의 다른 말이고, 두 말이 모두 담담한 흔한 말이다(밝혔다 / 말했다, 열렸다 / 개최됐다, 하기로 했다 / 한다).
  - `att`: 태도·정도·평가가 실릴 수 있는 말이 한쪽에 있다. 같은 장면을 한쪽은 담담하게, 한쪽은 평가를 담아 썼거나, 평가·정도의 말이 한쪽에만 있다(대뜸, 거세게, 무려, 끝내, 급증했다, 인정했다 / 실토했다).
  - `name`: 같은 대상을 다른 이름으로 부른다(개정안 / 개악, 시민 / 시위꾼).
  - `cert`: 확신이나 출처 표시가 다르다(확인됐다 / 알려졌다, 검토하고 있다 / 추진하고 나섰다, 전망이다 / 했다).

`syn`, `fact`, `other`는 분명할 때만 고른다. `att`·`name`·`cert`인지 애매하면 그중 가까운 것을 고른다. 어느 쪽이 더 센지는 다음 단계에서 따로 판단한다.

## 예 (다른 사건)

1. L "…정동영 통일부 장관에게 대뜸 "북동영 장관님?"이라고 호칭하며 질의를 시작했다" / R "…정동영 통일부 장관을 향해 "북동영 장관"이라고 지칭했다". 후보 «대뜸»: cp = R의 '향해', who = rep, kind = att.
2. L "민주당 의원들은 거세게 항의했다" / R "민주당 의원들은 맞서며 반발했다". 후보 «거세게 항의했다»: cp = R의 '맞서며 반발했다', who = rep, kind = att.
3. L "밴스 부통령이 이란 강경파 인사와 직접 회담하는 방안을 검토하고 있다" / R "밴스 부통령이 이란 강경파 인사와의 직접 대면 협상을 추진하고 나섰다". 후보 «검토하고 있다»: cp = R의 '추진하고 나섰다', who = rep, kind = cert.
4. L "정부는 내년 예산안을 발표했다고 밝혔다" / R "정부는 내년 예산안을 발표했다고 말했다". 후보 «밝혔다»: cp = R의 '말했다', who = rep, kind = syn.
5. L "19일 오후 서울 여의도에서 집회가 열렸다" / R "서울 여의도에서 집회가 열렸다". 후보 «19일 오후»: cp = 없음, who = rep, kind = fact.
6. L "여야 의원들이 설전을 벌였다" / R "민주당 의원은 …라고 주장했다". 후보 «설전을 벌였다»: cp = R의 '주장했다', who = rep, kind = other(여야의 말싸움 전체와 한 의원의 발언은 같은 부분이 아니다).
7. L "관계자를 인용해 이같이 보도했다" / R "…것으로 전해졌다". 후보 «관계자를 인용해»: who = rep, kind = other(출처 표시와 문장 끝 전언은 같은 부분이 아니다).
8. L "공단은 단속을 강화하기로 했다" / R "공단은 단속을 강화한다". 후보 «하기로 했다»: cp = R의 '강화한다', who = rep, kind = syn.

입력의 모든 짝과 모든 후보에 한 번씩 답한다.
