# 어느 쪽 표현이 더 센가

같은 사건을 다룬 두 기사에서 같은 사실을 전하는 두 문장을 보여 준다. 두 문장에서 서로 다르게 쓴 부분을 [[ ]]로 표시했다(표현 1, 표현 2). 짝마다 세 칸을 차례로 고른다.

- `same`: 두 [[ ]] 표현이 같은 대상, 같은 행위, 같은 수치를 가리키는가 — `y` / `n`
  - `y`: 같은 대상이나 현상을 다른 이름, 평가가 담긴 말로 불러도 `y`다(개정안 / 개악, 집회 참가자 / 시위꾼, 사고 / 참사). 이름이 다른 것 자체가 비교할 차이다.
  - `n`: 견줄 수 없는 짝이다. 한 표현이 다른 일, 다른 사람의 말, 다른 지역·다른 수치, 제목 같은 다른 부분을 가리킨다. 또는 한 표현이 조사·기능어뿐이거나, 문장 안에서 서로 다른 자리(행위와 대상, 원인과 결과)에 있다.
- `str`: 일반 독자에게 어느 표현이 태도·평가·감정·정도·확신을 더 싣고 있는가 — `1` / `2` / `sim`(비슷하다)
- `seen`: 뉴스를 가끔 읽는 일반 독자가 두 문장을 나란히 봤을 때, 설명을 읽지 않아도 이 차이를 바로 느끼는가 — `y` / `n`

`same`이 `n`이면 `str`은 `sim`, `seen`은 `n`으로 둔다.

판단할 때 볼 것

- 같은 일을 한쪽은 담담한 말로, 한쪽은 감정·평가·과장이 실린 말로 썼으면 실린 쪽이 세다. 이런 차이는 보통 바로 느낀다.
- 장면을 평가하거나 정도를 키우는 말(대뜸, 거세게, 무려, 불과, 끝내)이 한쪽에만 있으면 그쪽이 세다.
- 확신이 다르면 더 단정하는 쪽이 세다(확인됐다 > 알려졌다, 추진하고 나섰다 > 검토하고 있다, 했다 > 할 가능성이 있다).
- 둘 다 흔한 기사 말투이거나 뜻과 세기가 같으면 `sim`이다(밝혔다 / 말했다, 달했다 / 이른다, 늘었다 / 증가했다).
- 수치의 오르내림을 전하는 흔한 동사끼리(오르다 / 뛰다 / 상승하다 / 확대되다)는 `sim`이다. 정도를 키우는 말(급등, 훌쩍, 그쳤다)이 있을 때만 차이다.
- 행위·변화를 서술하는 말끼리 다를 때는 한쪽에 평가·감정·과장이 분명히 실려 있을 때만 차이다. 뜻이 가까운 다른 말(늘다 / 증가하다, 이어지다 / 지속되다, 높다 / 두드러지다, 원인이 되다 / 영향을 주다)은 `sim`이다.
- 앞뒤 문장을 잇는 말(반면 / 한편, 특히 / 무엇보다, 또 / 이어)끼리는 `sim`이다.
- `str`이 `sim`이면 `seen`은 `n`이다.
- 문장 1·2의 순서는 원문·비교 기사와 상관없다.

## 예 (다른 사건)

1. 문장 1 "…부정행위를 저질렀다고 [[인정하고]]…" / 문장 2 "…부정행위를 했다고 [[실토하자]]…": same = y, str = 2, seen = y. 실토는 숨기던 잘못을 털어놓는다는 느낌을 준다.
2. 문장 1 "…라고 관계자는 [[말했다]]" / 문장 2 "…라고 관계자는 [[밝혔다]]": same = y, str = sim, seen = n.
3. 문장 1 "…장관에게 [[대뜸]] "북동영 장관님?"이라고 호칭하며…" / 문장 2 "…장관을 [[향해]] "북동영 장관"이라고 지칭했다": same = y, str = 1, seen = y.
4. 문장 1 "…직접 회담하는 방안을 [[검토하고 있다]]" / 문장 2 "…직접 대면 협상을 [[추진하고 나섰다]]": same = y, str = 2, seen = y.
5. 문장 1 "…지급액은 2조 원에 [[달했다]]" / 문장 2 "…지급액은 2조 원에 [[이른다]]": same = y, str = sim, seen = n.
6. 문장 1 "…적발 건수가 전년보다 10% [[급감했다]]" / 문장 2 "…적발 건수가 전년보다 10% [[감소했다]]": same = y, str = 1, seen = y.
7. 문장 1 "…여야 의원들이 [[설전을 벌였다]]" / 문장 2 "…민주당 의원은 …라고 [[주장했다]]": same = n. 여야의 말싸움 전체와 한 의원의 발언은 같은 것을 가리키지 않는다.
8. 문장 1 "…서울 아파트값은 지난주보다 0.2% [[오르는 데 그쳤다]]" / 문장 2 "…부산은 0.1% [[내렸다]]": same = n. 다른 지역의 다른 수치다.

입력의 모든 짝에 한 번씩 답한다.
