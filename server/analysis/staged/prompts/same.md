# 두 문장이 같은 일을 전하는가

같은 사건을 다룬 두 기사에서, 프로그램이 같은 내용일 수 있는 문장끼리 짝지어 두었다(L은 원문 기사 문장, R은 다른 언론사 문장). 짝마다 아래 항목을 보기에서 골라 답한다. 오래 생각하지 말고 문장에 드러난 대로 답한다. 이유는 쓰지 않는다.

1. `actor`: 두 문장이 전하는 일의 행위자(누가 했나·말했나)가 같은가
   - `same`: 같다. 같은 사람·집단을 다른 이름이나 직함으로 불러도 같다.
   - `different`: 다르다(여당 의원 대 야당 의원, 정부 대 시민단체).
   - `missing`: 한쪽이나 양쪽에 행위자가 드러나지 않는다.
2. `act`: 행위·발언·상황(무엇을 했나·말했나·어떤 상태인가)이 같은가
   - `same`: 같다. 같은 일을 평가가 실린 다른 말로 서술해도 같다(항의했다 / 반발했다, 검토 / 추진). 같은 발언을 직접 인용과 간접 인용으로 옮겨도 같다. 한쪽은 일어난 일로, 한쪽은 가능성으로 써도 같은 일이면 같다(확산하고 있다 / 확산할 수 있다).
   - `partial`: 두 문장이 함께 전하는 사실이 하나라도 있다. 문장의 중심 서술이 달라도, 꾸밈절이나 부사절 속 사실을 함께 전하면 여기에 든다. 예: "응시자 평균이 30.18점이었던 과목에서 100점을 받았다" / "평균 점수가 30.18점에 그친 어려운 과목이다"는 평균 점수라는 사실을 함께 전한다.
   - `different`: 함께 전하는 사실이 없다. 단계가 다른 일(상임위 처리 / 본회의 통과), 다른 사람의 발언, 다른 장면, 원인 / 결과.
3. `scene`: 시점·장소·계기가 같은가 — `same` / `different` / `unknown`(한쪽에 드러나지 않음)
4. `kind_l`, `kind_r`: 각 문장의 성격
   - `fact`: 일어난 일이나 확인된 상태를 전함
   - `forecast`: 앞으로의 일, 가능성, 전망
   - `interpretation`: 기자가 일의 의미나 배경을 해석·평가함(-다는 뜻이다, -로 풀이된다, 셈이다)
   - `ought`: 해야 한다는 주장·요구

입력의 모든 짝 번호에 한 번씩 답한다.
