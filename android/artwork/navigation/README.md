# App icons

SVG sources are from [Lucide](https://github.com/lucide-icons/lucide):
`house`, `newspaper`, `bookmark`, `user-round`, `arrow-left`, `arrow-right`,
`chevron-left`, `chevron-right`, `chevron-up`, `chevron-down`, `search`, `x`,
`sun`, `chart-line`, `arrow-right-left`, `menu`, `arrow-up-right`, `plus`,
`check`, `book-open`, and `columns-2`.

The corresponding Android vector drawables preserve the original 24-unit grid,
2-unit rounded stroke, and geometry. Color comes from the active app theme.
Keep the source SVG and native drawable in sync when updating an icon.
`bookmark_filled` uses the same bookmark silhouette with a solid fill for the
saved state, so selection does not change the icon's proportions.

See `LICENSE` for Lucide and Feather attribution.
