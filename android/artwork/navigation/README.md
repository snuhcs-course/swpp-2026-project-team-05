# Navigation icons

SVG sources are Lucide `house`, `newspaper`, `bookmark`, `user-round`,
`arrow-left`, and `chevron-right`: https://github.com/lucide-icons/lucide

The corresponding Android vector drawables preserve the original 24-unit grid,
2-unit rounded stroke, and geometry. Color comes from the active app theme.
Keep the source SVG and native drawable in sync when updating an icon.

See `LICENSE` for Lucide and Feather attribution.
